# hxyfront-62014 赛鸽训放与饲料批次核验台

源提示词编号：9

面向赛鸽棚的**离线**训放记录与饲料批次核验前端工具。全部数据保存在浏览器
localStorage，支持存档导出/导入 JSON，无后端依赖。

## 业务规则

- 距离分级：≤100km 短训，101–300km 中训，>300km 长训。
- **每羽同日只能排一次长训**（当日仍可短训，次日恢复）。
- 饲料批次**停用**、日粮**不足**（余量 < 0.05kg）或**体重偏离区间**、**健康异常**时：
  只能安排短训，不得进入中长距离排行。
- 登记地点、距离、天气、放飞时刻、归巢时刻与用时（用时可按时刻自动核算后手改）。
- **未归巢与健康异常鸽不参与排行**，未归巢记录进入失联提醒。
- 更正饲料、体重或放飞参数后，排行与未归巢提醒**立即重算**；
  更正以追加版本方式留档，**旧版只读**。

## 三个业务文件

| 文件 | 职责 |
| --- | --- |
| `src/rules.ts` | 规则层（纯函数）：距离分级、饲料/体重/健康核验、排训判定、排行与未归巢计算 |
| `src/archive.ts` | 存档层：localStorage 持久化、种子数据、登记/更正的不可变版本管理、导入导出 |
| `src/App.tsx` | 页面交互层：鸽棚总览、登记/更正、成绩排行、单羽档案、饲料批次核验 |

标签页、距离/血统筛选与选中档案随视图状态持久化，**刷新后列表、筛选与档案一致**。
