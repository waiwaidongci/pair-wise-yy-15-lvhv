# hxyfront-62014 赛鸽训放与饲料批次核验台

离线（纯前端、数据仅存本机浏览器 localStorage）的赛鸽训放登记、饲料批次核验与成绩排行工具。

## 业务规则

- **距离分级**：短训 < 80km；中距离 80–<200km；长距离 ≥ 200km。
- **短训限制**：饲料批次停用、日粮不足（库存 < 分配羽数 × 日粮标准）或体重偏离区间（低于下限/高于上限）的赛鸽只能排短训，且不进入中长距离排行。
- **排训限制**：每羽同日只能排一次长训（同日再排长训登记时直接拦截，短训不受此限）。
- **排行资格**：仅已归巢、归巢时刻有效、健康正常、无短训限制的中/长训记录可上榜，按分速（m/min）降序。未归巢、健康异常鸽不参与排行。
- **登记内容**：赛鸽、日期、地点、距离、天气、放飞时刻、归巢时刻（可标记未归巢）；自动计算用时与分速。
- **即时重算**：更正饲料批次、体重或放飞参数后，排行、未上榜原因与未归巢提醒立即重算。
- **旧版只读**：每次更正都把旧值/旧记录快照写入修订存档，存档只读，不可再编辑。

## 三个业务文件

| 文件 | 职责 |
| --- | --- |
| `src/rules.ts` | 规则层（纯函数）：距离分级、饲料/体重核验、排训校验、排行、排除名单、未归巢提醒 |
| `src/archive.ts` | 存档层：localStorage 读写、种子数据、结构校验、修订快照归档（旧版只读） |
| `src/App.tsx` | 页面交互层：总览指标、批次核验、鸽棚档案、训放登记/更正、记录筛选、排行、提醒、单羽履历弹窗 |

筛选条件与全部数据均持久化，刷新后列表、筛选与档案保持一致。
